## Дневник выполнения работы

### 14.11.2026. Вставка и поиск

Реализованы вставка и поиск по строковому ключу. Корень и дочерние узлы хранятся в `unique_ptr`, а ссылка на родителя представлена обычным указателем.

Для проверки использован тестовый `main` в `koch_derevo.cpp`. Среда работы — WSL Ubuntu, компилятор — `g++`, стандарт — C++17.

| Действие | Фактический результат |
| --- | --- |
| Вставка `mango → 10`, `apple → 20`, `pear → 30` | Все три вызова вернули `true` |
| Повторная вставка `apple → 99` | `false` |
| Поиск `apple` | Найдено исходное значение `20` |
| Поиск `pear` | Найдено значение `30` |
| Поиск отсутствующего `banana` | `false` |
